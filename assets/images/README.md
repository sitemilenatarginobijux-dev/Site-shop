# Fotos de produtos

Adicione nesta pasta as fotos reais da loja, de preferência em WebP ou JPEG otimizado.

Sugestão de padrão de nomes:
- `argolas-prata-925-frente.webp`
- `argolas-prata-925-detalhe.webp`
- `argolas-prata-925-no-corpo.webp`
- `colar-folheado-ouro-detalhe.webp`

Para cada peça, procure incluir:
1. Foto de produto em fundo neutro e bem iluminado.
2. Foto macro para mostrar acabamento, cravação e detalhes.
3. Foto no corpo para demonstrar escala e caimento.
4. Vídeo curto vertical, de 3 a 5 segundos, quando disponível.

As artes geométricas atuais na página inicial são ilustrativas, não fotografias nem imagens de produtos reais.
